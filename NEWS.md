# News

## Latest (1.0.0)

openRender 1.0.0 is the first release under the openRender name, rebranded from Pixie. It includes:

- CMake-based build and install
- Documentation converted to Markdown (README, INSTALL, LICENSE, AUTHORS, etc.)
- Semantic versioning (MAJOR.MINOR.PATCH)

For a detailed list of changes, see [ChangeLog.md](ChangeLog.md).

## Since 5399a1b (2025-08-27 – 2026-02-10)

- (2026-06-07 – 2026-07-08) LLVM JIT shading engine: `oshader --jit` now compiles RSL shaders to LLVM bitcode (`.slo`), executed natively at render time via LLJIT. The compiler and interpreter runtime are extracted into a new `src/libshader/` library hierarchy. New `sloinfo` binary auto-detects `.slo` vs `.rslo` format. Shader format selection added at three levels: `Attribute "shade" "shaderformat"` (per-primitive), `Option "shaderformat" "default"` (scene-wide), and `OPENRENDER_DEFAULT_FORMAT` env var (compile-time fallback). Structured logging via `ORENDER_INSTR_LEVEL`/`ORENDER_INSTR_OUTPUT` environment variables. Eight `cellnoise` ops added to the JIT emitter. Coordinate transforms (`vtransform`, `ntransform`, `ptransform`) corrected. `lightTags` fix prevents non-illuminated vertices from receiving spurious light contributions in the JIT path. Shader-space parameter defaults at bind time fixed via `jitSetInitXform` thread-local fallback (`somewood` vein orientation). Visual regression suite expanded to 43 scenes, including `.slo` JIT parity tests.

- (2026-05-31) Fixed a shader compiler bug where the CSE optimizer shared its expression cache across all IR basic blocks, causing constant loads inside if/else branches to silently corrupt subsequent code. The regression was visible in `windowhighlight.sl` (sphere highlight shape wrong vs. PRMan 3.9). CSE is now intra-block only. Separately, the `oshader` compiler now rejects `Ps` (the illuminated surface point) inside surface shaders — it is only defined in light shaders per RI Spec. Scope enforcement is backed by a new per-variable scope mask checked on every built-in variable lookup.

- (2026-05-28) Fixed the imager shader pipeline to match the RenderMan spec (Render → Exposure → Imager → Quantize). Exposure is now applied in `CRenderer::dispatch()` before the imager shader runs, so imager shaders correctly receive post-exposure color and coverage values. All four file-format display plugins (TIFF, PNG, OpenEXR, RGBE) are refactored to share a common base class (`CFileOutputBase`) that handles scanline accumulation, thread safety, quantization, and dither; `file_base.h` is now installed for third-party display plugin authors.
- (2026-05-27) Python (`prman.py`) and Lua (`prman.lua`) language bindings are now proper install targets. Both are installed under `python/` and `lua/` in self-contained builds, or under `share/openRender/{python,lua}/` in FHS installs. Destinations can be customized at configure time with `-DOPENRENDER_PYTHONDIR` and `-DOPENRENDER_LUADIR`.
- (2026-05-27) Overhauled the build system for distribution-quality output: `libri.a` and `librslo.a` static archives are now installed alongside their shared counterparts; shared libraries carry proper `VERSION`/`SOVERSION` metadata; executables embed RPATH for relocatable installs; and self-contained builds automatically bundle external dependencies (libtiff, libpng, OpenEXR, etc.) with correct `@rpath`-relative IDs on macOS.
- (2026-05-19–2026-05-24) Added `orender-wire`, an interactive RIB wireframe scene previewer shipping as a native Metal/AppKit application on macOS and a GTK 4/OpenGL binary on Linux. Built on `libribpreview`, a new static library that tessellates all RenderMan primitive types into a flat line-list with per-vertex surface colors. Includes a full arcball camera, camera export/replace, and a 9-tessellator test suite. Decoupled from the full renderer — works without `ORENDERHOME`, `SHADERS`, or `DISPLAYS`. Removed the legacy `src/gui/` Qt/FLTK directory.
- (2026-05-19) Completed the full rename of the shader subsystem from `sdr` to `rslo`, including internal directories, library names (`librslo`), and tool names (`rsloinfo`). Unified RIB output initialization and added standard compliant preamble headers to all RIB generated by C++, Python, and Lua interfaces.
- (2026-03-10) Updated the compiled shader extension from `.sdr` to `.rslo`. The `oshader` compiler now outputs `.rslo` by default, while maintaining full backward compatibility for existing `.sdr` shaders. Added `--legacy-sdr` flag to `oshader`.
- (2026-02-08–2026-02-10) Completed the openRender rebrand, added speckit tooling, rewrote the README, and introduced Geometry RIB statement support with updated geometry definitions.
- (2026-01-02–2026-01-04) Added new shaders, RIB examples (including the Utah Teapot and wood materials), custom geometry, and NSI documentation references.
- (2025-12-27–2025-12-31) Simplified math macros, enhanced versioning and path handling, and refreshed shader assets and `.gitignore` entries.
- (2025-12-12–2025-12-16) Migrated documentation to a Hugo-based site with a dedicated theme, CI-based deployment, and updated configuration.
- (2025-12-07–2025-12-08) Modernized the codebase for C++20/C17 with improved 64-bit portability and portable I/O for photon maps, point clouds, and deep shadow maps; standardized formatting and documentation across core components.

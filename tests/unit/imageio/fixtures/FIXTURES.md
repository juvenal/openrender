# Fixtures of the OIIO decode tests (spec 048, Phase 4)

Generated by `tests/unit/imageio/tools/gen_fixtures.cpp` (libtiff, libpng, OpenEXR; `gen_fixtures <output-dir>`), checked
in, and not regenerated by the suite (libtiff and libpng bytes may differ by version). The spec 018 fixtures
(`tests/unit/image_input/fixtures`, formulas in its `FIXTURES.md`) are reused as they are and are never edited.

## Closed-form samples

For a pixel `(x, y)` and channel `c` of a `W x H` image:

- 8-bit: `u8(x,y,c) = (13x + 7y + 31c + 5) mod 256`
- 16-bit: `u16(x,y,c) = (1021x + 517y + 4099c + 7) mod 65536`
- float: `f32(x,y,c) = ((7x + 13y + 5c) mod 1000) / 997.0f - 0.25f`
- RGBE flat pixel: `r = 3 + (11x + 5y) mod 250` (never 2, so no flat pixel looks like an RLE marker), `g = (7x + 3y) mod 256`,
  `b = (5x + 13y) mod 256`, `e = 110 + (x + y) mod 30` (never the exponent bytes 40, 223, 226)
- smooth half/float EXR: `((7x + 13y + 5c) mod 1000) / 997.0f` (half: rounded to half)

## `parity/` (24x16 unless noted): both paths decode these identically, bit for bit

| File | Content |
|---|---|
| `tiff_{u8,u16,f32}_{1,2,3,4}.tif` | 12 TIFFs, 8-bit, 16-bit and float, 1 to 4 channels; MINISBLACK for 1-2, RGB for 3-4; EXTRASAMPLES unassociated alpha for 2 and 4 |
| `odd_rgb8.tif`, `odd_rgb8.png`, `odd_rgb.hdr`, `odd_rgb.exr` | 37x23 RGB (not tile- or block-aligned): u8 for TIFF and PNG, the RGBE formula, float for EXR |
| `png_u16_{2,3,4}.png` | 16-bit gray+alpha, RGB, RGBA (the 018 set has 8-bit 1 to 4 channels and 16-bit gray) |
| `hdr_flat_24x16.hdr` | flat (not RLE) RGBE |
| `exr_half_rgba.exr`, `exr_half_1ch.exr`, `exr_f32_rgba.exr` | half RGBA, half single-channel `Y`, float RGBA (only with OpenEXR) |
| `exr_half_edge.exr` | half RGB whose sample bits cycle through: +0, -0, the smallest and largest denormal, the smallest normal, +-1.0, 1/3, +-65504, +-inf, a quiet NaN, 0.5, a denormal, 100.0. The decoded float must equal the exact widening; NaN is compared by class |

## `refusals/` (both paths must refuse)

`png_interlaced.png` (8x8 Adam7), `png_gray4.png` and `png_gray1.png` (sub-8-bit), `tiff_tiled.tif` (32x32, 16x16 tiles),
`tiff_bilevel.tif` (1 bit per sample), `exr_two_channel.exr` (R, G) and `exr_deep.exr` (deep scanline; with OpenEXR), and
`fmt.jpg`, `fmt.tga`, `fmt.bmp`, `fmt.webp` (a few hundred bytes each; refused by the suffix table, and by the
`format_name()` check when a test renames them to a known suffix). The 018 negatives (`*_indexed.png`, `*_multipart.exr`,
`*_unsupported_channels.exr`) are reused. Truncated, corrupted and renamed copies are made by the tests in a scratch
directory.

## `colour/`

`cicp_rgb8.png` (24x16 RGB8 `u8`, a hand-written `cICP` chunk: primaries 9, transfer 16, matrix 0, full range, with its CRC) and
`other.ocio` (a small OpenColorIO v2 configuration with its own colour spaces, different from OCIO's built-in one).

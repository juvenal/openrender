# kind is prefix | file. A file rule beats a prefix rule; among prefixes the
# longest wins. Paths are repo-relative; @build/ marks generated sources in
# the build tree. Every scanned file must classify, or archcheck exits 2.

# as a violation instead of being reclassified away. File rules exist only
# for the forwarding shims, the plug-in ABI headers and generated sources.

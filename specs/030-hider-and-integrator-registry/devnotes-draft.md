| Hider and integrator registry (spec 030) | Implemented through Phase 10 (2026-11-11); results on macOS and on Linux (Ubuntu 24.04, GCC 13 `-Werror`) in `specs/030-hider-and-integrator-registry/validation.md`. Hiders and integrators are registered tables: the renderer core selects a hider through `hiderRegistry()` and never names one (DB-013 resolved: the `strcmp` chains, the `dynamic_cast<CReyes *>`, the TSM name test and the `hiderFlags` description bits are gone; the hard-coded `spherelight`/`quadlight` C++ lights, `hcshader`, are retired). Integrators are a new domain, Transport (constitution 1.4.0, `src/ri/transport/`), with a registry, a capability vocabulary, a pair check and the built-in `classic`; the `Integrator` statement exists in RIB, the C API, `ribOut` and the Python and Lua helpers, an unsupported (hider, integrator) pair refuses the frame with one error and an integrator parameter nobody defines is an error. Allowlist: 3 DB-011 lines and 1 DB-006 line deleted, none added (DB-011 164 -> 161, DB-006 30 -> 29); the Hiders `CRenderer::` metric 556 -> 553 references. No image changed on either platform: on macOS the suite (915 baseline images) and the determinism sweep (419 of 419) are byte-identical to the starting tree's, and on Linux (Ubuntu 24.04, GCC 13 `-Werror`) the final suite (960 images against a 915-image manifest) and the determinism sweep (419 of 419) are byte-identical too, with `-L architecture` 33 of 33; the Linux failures are the known GitHub #45 (`TextureTile_RenderByteIdentical`), #163 (photon rows) and a self-skip. SC-010 timing: teapot-somewood-reyes 5.29 s -> 5.20 s and killeroo-raytrace 9.02 s -> 9.18 s, both within the run-to-run spread. Known open: GitHub #163 (the photon hider's photon map differs from run to run, which makes `Registry_IntegratorImageIdentity`'s photon rows intermittent). The hider and integrator table interfaces are 2.0.0 and internal until spec 051. |

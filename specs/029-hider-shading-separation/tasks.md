## Implementation strategy

**MVP is Phases 1 to 4 (User Stories 1, 2, 5 and the P1 stories of the spec).** After Phase 4 `libshader_shading` has no import and no unresolved symbol, the static consumer launches with no workaround on both platforms, DB-001 and DB-005 are empty in the allowlist, the load stub and the package block are gone, and every image is byte-identical to the starting tree's. The rest is incremental, one concern per phase, each ending in a byte-identical checkpoint on both hosts and a pause:
- Phase 5 turns the hiders into owners of a `final`, virtual-free context (the largest phase; it can split at the hooks); Phase 6 makes each hider the tracer of its context and removes the adapter and the per-frame slot; Phase 7 makes `shade()` consume `ShaderGlobals` and removes the last Shading include of Geometry; Phase 8 updates the registry, validates the finished tree and runs the sweeps.
- Each phase leaves the tree green at its checkpoint, so any checkpoint PAUSE is a safe stopping point; a TEST-APPROVAL pause is taken before the phase's tests are enabled red, so the tree is green there too.

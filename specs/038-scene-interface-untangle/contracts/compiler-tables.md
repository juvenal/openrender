# Contract: the standalone compiler and its tables (FR-017-FR-019, US5)

Research M10, R10, R11.

## The compiler's own tables: `src/libshader/compiler/builtinTables.cpp`

Defines the two arrays `llvmEmitter.h` already declares, with unchanged types and external linkage:

```cpp
extern const OpcodeParamEntry kOpcodeParamTable[];      // {text, PARAMETER_* bits}, {nullptr, 0} terminated
extern const char *const kAllFunctionMnemonics[];       // texts, nullptr terminated
```

- Same rows, same order as the expansion they replace (`llvmEmitter.cpp:159-211`): `scriptFunctions.h`'s
  chain then `scriptOpcodes.h`'s chain for `kOpcodeParamTable`, `scriptFunctions.h`'s chain alone for
  `kAllFunctionMnemonics`; the non-`INIT_SHADING` expansion; both `"XXX"` rows kept, as rows.
- Parameter bits written as the engine spells them (`PARAMETER_RAYTRACE | PARAMETER_DERIVATIVE |
  ...`, `0`), from `common/rendererc.h`.
- Header comment: generated by `test_libshader_compiler_table_drift --emit`, not edited by hand; when
  the engine's tables change, the drift test fails and the file is regenerated with that command.
- `llvmEmitter.cpp` loses both blocks and its includes of `scriptFunctions.h`/`scriptOpcodes.h`; its
  `#include "common/rendererc.h"` moves with the table if the emitter no longer needs it.
- `compiler/opcodes.cpp`'s `kAllOpcodeMnemonics` is already the compiler's own and stays.

## The compiler's include path (`src/libshader/compiler/CMakeLists.txt`)

Removed: `include_directories(AFTER ...)` of `src/ri`, `hiders`, `render`, `state`, `parse`,
`geometry`, `texture`, `output`, `core`, `dataviewer` (`:8-17`), the PRIVATE `src/ri` (`:74`) and
`src/libshader/shading` (`:82`) with its comment. Kept: the compiler's source and binary
directories, `src/` (for `common/` and `shadeop/`), `src/libshader/include`, LLVM, and what the
linked `openrendercommon`/`openrendershadeop` targets export (`src/include` for `logging.h`).

## `Compiler_IncludeBoundary` (`cmake -P`, label `architecture`)

Inputs: `$<TARGET_PROPERTY:libshader_compiler_obj,INCLUDE_DIRECTORIES>`, the compiler's source list
and generated parser sources. Fails if:
1. a directory is `src/ri` or below, or `src/libshader/shading` or below;
2. a `#include "x"` of a compiler source resolves (compiler directory first, then the path in order)
   to a file outside: `src/libshader/compiler`, the compiler's build directory, `src/common`,
   `src/include`, `src/shadeop`, `src/libshader/include`, the top-level build directory (`config.h`,
   `version_config.h`), the LLVM include directories.
Red on the starting tree (rule 1, and `scriptFunctions.h`/`scriptOpcodes.h` for rule 2).

## `LibShader_CompilerTableDrift` (`src/libshader/tests/test_compiler_table_drift.cpp`, consumer)

Includes the engine headers under its own `DEF*` macros (like `test_used_parameters_table.cpp:49-50`)
and links the compiler's arrays.

| Compared | Against | Rule |
|---|---|---|
| `kOpcodeParamTable` | engine `scriptFunctions.h` + `scriptOpcodes.h` rows, (text, `static_cast<unsigned>(par)`) | same count, row i equal in text and bits |
| `kAllFunctionMnemonics` | engine `scriptFunctions.h` chain, text | same count, row i equal |
| `kAllOpcodeMnemonics` (`compiler/opcodes.cpp:191`) | engine `scriptOpcodes.h` chain, text | the relation measured in Phase 1 (research R10a), every exception named in the test |

- On any difference: print the first differing row of each table (index, both sides) and fail.
- `--emit`: print `builtinTables.cpp` from the engine side (rows stringified from each `par`
  argument), for regeneration.
- Self-check: run the comparator on a copy of each compiler table with one row's text changed and
  one row's bits changed; both must be reported. This is the test's red evidence (Q3).
- Registered `DISABLED` until `builtinTables.cpp` exists (it cannot differ before); enabled in the
  same phase. `LibShader_UsedParametersTable` and `LibShader_OpcodeCoverage` keep their meaning.

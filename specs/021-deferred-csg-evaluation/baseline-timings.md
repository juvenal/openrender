# Master Baselines (T014)

**Feature**: 021-deferred-csg-evaluation | **Recorded**: 2026-10-01 | **Code**: master behaviour at `ff3eec0` (Phase 1 adds only empty stubs, the metric tool, the harness and scenes)

Produced by `tools/baseline.py` (raw results: `tools/baseline-master.json`; tables: `tools/baseline_report.py`). Scenes are generated by `tools/gen_scenes.py`, which also computes the analytic data in their headers.

## How these numbers were taken

- Apple M2 (arm64), Release build, one render at a time under `nice -n 15 taskpolicy -b` (the maintainer's thermal preference). Background priority stretches wall-clock time, so these are throttled times: compare them only against later runs taken the same way (T081).
- Each scene rendered once with `orender -x 3` and the visual-suite environment (`ORENDERHOME=build/tests/visual/_home`).
- The checks are the Phase 3 registrations' planned arguments, run directly with `test_csg_seam_metric` on these renders.

## Metric tool validation

Before trusting the master results, the tool was checked against renders with no solid block, so no CSG defect can be involved:

| Check | Result |
|---|---|
| Plain `Sphere 1.5`, silhouette radius vs analytic 122.7 px (`--annuli`) | 0.20 px |
| Two plain overlapping spheres (visually identical to their union): `--projected-curve` with the rational-NURBS header circle | 0.69 px (edge threshold 0.05; the earlier 0.1 default missed antialiased seams, so 0.05 is now the default) |
| Same two-sphere scene, REYES vs raytrace, `--edge-compare` | 0 px (needed hysteresis: without it, edges near the threshold flicker between hiders and read up to 5 px) |
| A render shifted by 1 / 2 / 3 px against itself, `--edge-compare` | 1 / 2 / 3 px |
| Plain sphere plus plain cube, sphere-cube arcs plotted on the image | samples lie on the visible seams; the projection matrix convention was confirmed with a marker render (3 markers within 0.1 px) |

- **Raytrace pole pixels on a plain sphere**: a plain `Sphere 1.5` viewed down its axis (no solid block) renders two pixels at the exact image centre (399,249 and 400,249) with alpha 242/255. The view ray passes through the sphere's pole. Pre-existing, unrelated to CSG; in the hero scene that pixel lies inside the clear hole, so no spec 021 test is affected.

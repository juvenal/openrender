## Conventions

- **Line numbers** are master `e83d005d` (the base of this branch). Re-locate by text if a line moved.
- **`[P]`** marks a task that touches files no other open task of its phase touches. A `CMakeLists.txt` that several tasks register into is edited by one task at a time. Without `[P]`, a task depends on the task before it.
- **Story labels**: `[US1]` to `[US9]` map to the nine user stories of spec.md (US1 interior fog on a non-CSG glass sphere, US2 exterior fog incl. misses, US3 transmission/shadow, US4 gather, US5 CSG as the general case, US6 atmosphere unchanged, US7 `incident()`/`opposite()`, US8 nothing else changes, US9 documents). Phases 0 and 6 and the shared-type block of Phase 2 carry none. Tasks that serve one FR across stories name the FR.
- **Build, test and tool runs** go through `~/.claude/bin/cpujob <label> <command>`: `-j4` at most on macOS, `-j2` for the determinism sweep and on Linux. A test binary is never run directly; the one exception is the golden capture (`tools/capture_goldens.sh`, T045), which runs `test_golden_compare --write` as a tool (it is not a ctest test, so it has no ctest timeout), always through `cpujob` and its `CPUJOB_TIMEOUT`; the scene generator also runs through `cpujob`. **No-volume twins** are named `<family>-none-<hider>[-slo]` (for example `volume-interior-fog-slab-none-raytrace-slo`). Every build or test task waits for the coordinator's go-ahead.
- **Hooks**: the optional `speckit.git.commit` hooks (before and after tasks and implement) are declined. Nothing is committed, merged or pushed by an agent. `git add` is allowed; each checkpoint stages that phase's files.
- **Stops**: a **TEST-APPROVAL** task opens a phase (in Phase 1 it follows the tests it approves, which have to exist to be shown). A **PAUSE** task is one named maintainer approval: the agent writes the proposal to a file under `specs/056-volume-shader-segments/tools/proposed/` (or shows the diff), reports, and does not apply it, or start any task that depends on it, until the maintainer approves. A **CHECKPOINT** closes every phase and ends with a report; the next phase does not start on its own.
- **Remote**: `H=juvenal@ubuntu-2404-desktop.v2-labs.io`, `R=/home/juvenal/Projects/Development/CLI/openrender-056`, always written `"${H}:${R}/..."` (zsh reads `$H:path` as a modifier). Only `${R}` is touched on the host: never `~/Projects/Development/CLI/openrender`, `openrender-029`, `openrender-038`, `cellar` or `shrimp`. Sync recipe (038's, verbatim in shape): `rsync -rlpc -0 --files-from=$WT/build-056-snapshots/files.list $WT/ "${H}:${R}/"` with `files.list` from `git -C $WT ls-files -z --cached --others --exclude-standard`, a `manifest.sha256` made on the Mac, `rsync` of the manifest, then `ssh "${H}" "cd ${R} && sha256sum -c --quiet manifest.sha256"`. Remote builds: `ssh "${H}" "cd ${R} && CPUJOB_TIMEOUT=7200 ~/.claude/bin/cpujob 056-pN-lx-build cmake --build build -j2"`; tests: `... ~/.claude/bin/cpujob 056-pN-lx-test ctest --test-dir build -LE determinism-sweep -j2 --output-on-failure"`. The sync does not delete: a retired file is removed with an explicit `ssh "${H}" "rm -f ${R}/<path>"` named in the task that retires it. T006 turns this into `tools/sync_linux.sh`.
- **Tolerances are fixed at approval** (they cannot be widened later): `VOLUME_PROBE_TOL_FOG = 0.0001` for a value that contains `exp()` (fog), `VOLUME_PROBE_TOL_COLOUR = 0.00001` for a pass-through colour, both absolute, on 32-bit float output. 0.0001 absorbs the macOS/Linux difference of about one ulp per `exp()` and the reyes/zbuffer/raytrace arithmetic differences on a constant segment length, with room. The atmosphere goldens and the `-none` twins are bit for bit per platform (`test_golden_compare`, no tolerance), like spec 039's occlusion golden.
- **Hand-computed fog** (every `VolumeProbe_*` expectation): `fog` is `Ci = mix(Ci, background, d)`, `Oi = mix(Oi, 1, d)` with `d = 1 - exp(-length(I) / distance)` (`shaders/fog.sl`). With `T = exp(-l/D)`, `d = 1 - T`, backdrop colour `Cb`, fog `background = bg` and segment length `l`: the attenuated colour is `Cb*T + bg*d`. A miss (`Ci = Oi = 0`) gives `bg*d`. A transmission through an opaque-to-fog segment gives `T` (grey, Q7). Every probed region has a constant `l`: orthographic camera, slabs or parallel planes, axis-aligned polygon bounds, a **non-identity** camera transform (research R11).

- **Checkpoint architecture step**: every checkpoint runs `ctest --test-dir $WT/build -L architecture` (through `cpujob`), which must pass with `tests/architecture/allowlist.txt` unchanged, and the expected-red comparison of the table below.
- **Records**: every checkpoint appends to `specs/056-volume-shader-segments/validation.md` (commands, counts, what is still red and why) and stages the phase's files.

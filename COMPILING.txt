
	
	Compilation Instructions for OPENRENDER

	Requirements:
	- libtiff:    Available from http://www.libtiff.org
	- flex/bison: Available on Unix platforms by default. You will have to search the internet to find the windows version. (available for free).
	- fltk:       Available from http://www.fltk.org This is only required if you want to compile the interactive viewer. This library is not required by the renderer.
	- openEXR:    Available from http://www.openexr.org This is only required if you want to compile the OpenEXR output driver.


	Compiling openRender is a two step process:
	1. Compilation
	2. Creating a binary distribution


-------->Compiling on Windows:

	With Visual Studio .NET
	- Open OPENRENDERHOME/windows/vcnetX/openRender/openRender.sln
	- Select Build -> Batch Build
	- Select the configurations to build
	- Hit "Build"

	After compilation
	- OPENRENDERHOME/bin will contain the binaries
	- execute OPENRENDERHOME/makeinst.bat
	- Your binary distribution is in OPENRENDERHOME/openRender


-------->Compiling on UNIX:

	For a self contained archive
	- go to OPENRENDERHOME
	- type "./configure --prefix=XXX --enable-selfcontained"
	  (XXX = the directory to put openRender. e.g. /tmp/openRender)
	- type "make"

	After compilation
	- type "make install"
	- Your binary distribution is in XXX

	Now you can take your binary distribution and move it anywhere. This is your new OPENRENDERHOME. This binary distribution should have the same directory structure and the same files no matter what platform you're on.


	No matter what compiler you're using, openRender takes quite long time to compile. This is primarily due to the massive amount of macros to make the renderer as efficient as possible. Some of the files that especially take long time are execute.cpp and stochastic.cpp. Just take your time, go to your favorite cafe and enjoy a nice cup of Java.
